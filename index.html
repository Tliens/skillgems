FAQ

What is an AI agent skill?

A skill is a folder built around a SKILL.md file: a short YAML frontmatter (name + description) followed by instructions, and optionally scripts and reference files. An AI agent such as Claude Code reads the description and loads the full instructions only when the task matches — so agents gain expert procedures without bloating every conversation.

How do I install a skill from this directory?

Open the GitHub repo from the card, then copy the skill folder into ~/.claude/skills/ for personal use, or .claude/skills/ inside a project to share it via git. Some skills ship as Claude Code plugins installable from a marketplace, and the Claude apps accept zipped skills under Settings → Capabilities.

Do skills work outside Claude?

The SKILL.md format is an open convention, and a growing list of tools supports it — including Claude Code, Claude desktop apps, Codex CLI, Gemini CLI, Cursor and other agents. Cards note where a skill is Claude-specific.

Are the skills listed here free?

The listed repositories are public and free to use. Most are open source under permissive licenses (MIT, Apache-2.0 and similar), but licenses vary per repository — check the license file before commercial redistribution.

Are skills safe to install?

Treat a skill like code from a stranger: it can contain instructions and executable scripts. Prefer official repos, skim the SKILL.md and any scripts before installing, and run a scanner such as NVIDIA SkillSpector on third-party collections. Every link in this directory was manually opened and verified on the date shown in the hero.

How is this directory maintained?

Entries are hand-curated rather than auto-scraped: each repository is opened and its metadata verified via the GitHub API. The verification date is shown at the top of the page, and the catalog ships a machine-readable data/catalog.json plus llms.txt for AI agents.

📦 What is a skill?

A folder with a SKILL.md

Each skill is a folder: a SKILL.md with a name, a one-line description and step-by-step instructions, plus optional scripts and reference files.

Loaded only when needed

The agent always sees the short description; the full instructions are loaded only when your task matches. Expertise on demand, without bloating context.

Runs where you work

Skills work in Claude Code, the Claude apps and the API — and the open format is adopted by Codex CLI, Gemini CLI, Cursor and more.

Procedures, not prompts

Skills encode how experts work: multi-step workflows, house rules, quality bars. Write once, and every future session starts from experience.

🛠 How to install & use

1
Pick a skill & open GitHub

Browse the directory, open the card that matches your task and hit the GitHub button to see the source, docs and license.

2
Drop it into your skills folder

Copy the skill folder into ~/.claude/skills/ for personal use, or .claude/skills/ inside a project to share it via git. Some repos install as plugins — follow their README.

3
Just ask — it triggers itself

Skills activate automatically when your request matches their description, or name them explicitly: “use the pdf skill to build a fillable form”.
